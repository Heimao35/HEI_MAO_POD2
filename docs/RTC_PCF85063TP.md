# PCF85063TP RTC 与时钟设置

## 硬件与依据

- 用户提供原始手册：`DOC/datasheet/PCF85063TP.pdf`，NXP PCF85063TP Rev.4，2015-05-06。不要用 PCF85063A/ATL 的闹钟/计时器寄存器替代本型号。
- SDA=GPIO48、SCL=GPIO47，复用 AXP2101/CS43131 的 I2C1；INT=GPIO11，开漏低有效输入，使用板上上拉与内部弱上拉。100kHz，7位地址 **0x51**，手册 A2h/A3h 是包含 R/W 位的8位地址。
- 手册第5页表5：00h Control_1，01h Control_2，02h Offset，03h RAM，04h..0Ah 为秒、分、时、日、星期、月、年。时间/日期为BCD，星期为二进制0..6（0=周日）。
- 第6/8/9页：Control_1[5] STOP，bit1 12_24，bit0 CAP_SEL。STOP 配合一次7字节写入实现一致设置；松开 STOP 后首个加秒约0.508秒，因此读回允许设置值或下一秒。
- 第18页：Seconds[7] OS 说明振荡器曾停振；不能将此读数当作已校准时间。只在用户明确设置时清OS。
- 第21页8.4：一次连续突发读将时钟寄存器冻结，整个访问必须少于1秒；采用11字节连续读，单事务超时100ms。
- 第11/12页：Control_2 MI 位启用分钟脉冲，只有 Offset.MODE=0 可使用；模式1保持频偏设置，只用轮询。保留COF时钟输出及CAP_SEL、Offset、RAM，不执行软件复位、不修改PMIC RTC供电。
- ESP-IDF锁定v5.5.4：本地 `components/esp_driver_i2c/include/driver/i2c_master.h` 与 `i2c_master.c`。复用已建立bus，后台同步事务由驱动总线锁串行化。乐鑫文档检索也确认get_bus_handle/事务锁用法，但检索命中latest，实际编译与接口以本地5.5.4为准。

## 实现与运行边界

`main/rtc_clock.c` 独占RTC寄存器，RAM快照/请求由短spinlock保护。UI只读写RAM；所有I2C在现有PMIC任务的BUSY/暂停门内进行，无额外任务栈。PMIC健康/故障采样仍为5s/2s，任务最多等待1s以服务RTC；PMIC IRQ、RTC IRQ和设置请求可立即唤醒任务。显式Light-sleep期间RTC I2C也停稳，GPIO11不加入EXT1唤醒源，原触摸/电源键唤醒不变。

配置RTC设备在PMIC总线初始化之后、后台任务启动之前完成。RTC缺失或读写失败不妨碍电源/音乐启动，之后继续轮询；设备初始化分配失败需重启后再初始化。PMIC任务启动失败会删除RTC GPIO handler/device再清理bus。RTC的分钟INT为刷新提示，1s轮询兜底；不添加闹钟或RTC定时唤醒。

UI公共状态增加time_valid/weekday；首次未校准、STOP、坏BCD/日期或I2C失败时，状态栏/锁屏显示未知，不能沿用演示时间。恢复有效读数后再次显示真实时间。有效范围采用2000..2099，跨世纪不保证；星期按独立计数器提供给用户选择，不强制由日期计算覆盖。

## 页面与操作

- 原设置页的“时钟”齿轮改为矢量圆形表盘+指针，仍是原100px按钮与原网格位置，不增加位图/字库图标。
- 点击进入新子页，从右向左滑入；左上无字返回箭头使页面向右滑出。两者用原350ms ease-out曲线。
- 第一行时/分，第二行年/月/日，第三行固定“周”+可滚动“一..天”。LVGL roller原生竖直吸附，三项可见，中项选中。年/月变更将日期夹到合法月末并处理闰年。
- 子页与滚轮不冒泡/链式传播到播放器、锁屏或设置页边缘手势。原设置页保留位置、上下浏览及顶部展开/底部收起动画。
- 有改动后返回只投递一次设置请求，秒归零；保存期间暂时禁用滚轮/返回。后台STOP->7字段突发写->恢复运行->连续读回校验，成功才滑出。失败留在原页并保留所选值，允许重试；可能部分写入失败后，本次开机不再自动信任读数，需重新成功设置。
- 无改动返回不写RTC、不重置秒；初次未知时编辑器中的2026-01-01仅为输入占位，未操作返回也不自动当成真实时间。
- 实体电源键进入锁屏时同样排队保存改动，页面收起不阻塞原锁屏动画。后台保存失败保留草稿，再次打开可重试。
- 普通页面每秒从RAM刷新时间；子页可见/保存未完成时100ms只查RAM完成状态，隐藏且完成后暂停此定时器。
- 锁屏原时间/日期位置字号保持，日期下方增加22px第三行星期；未知时显示“时间未设置”。

## 字库制作清单（本次功能用字，按字号去重）

这是需要**合并到现有对应字库**的字符，不可直接用此清单替换原全系统字符集合。

- 14px：没有新增；原设置入口“时钟”仍使用14px。
- 16px：`时分年月日周返回自动保存失败请重试正在未校准设置间钟就绪`；另包含中文逗号`，`和英文句点`.`。用途：时/分/年/月/日/周、保存/错误/未校准提示。
- 22px：`时钟设置一二三四五六天星期间未`。用途：标题、星期滚轮、锁屏星期及未知时间提示。
- 18px：原18px全字库不变；本功能无新增18px文字。
- 数字滚轮/冒号/返回箭头：LVGL内置Montserrat26；锁屏时分/日期沿用内置48/26；状态栏沿用16。

原14/16/22二进制字体保持原同字号内置字库fallback；内置Montserrat不包含中文，新中文必须实际合入这些bin后才会正常显示，不能依赖图标fallback补汉字。更新文件后重新构建并烧录fontfs镜像；无需改分区表。此改动不生成或覆写用户字库文件。

- 主机测试使用实际生产RTC实现与LVGL，不访问真实板子。覆盖BCD/闰年/坏日期/OS/STOP/12小时制、失败恢复、读回不符、MODE=1不启用MI、ISR无I2C、真实设置入口点击/滚轮拖动/吸附、边界、未修改返回/保存失败重试/电源锁屏保存和锁屏未知星期。
- ESP-IDF v5.5.4固件编译与20项主机回归结果见本轮工作日志；不能据此宣称实板走时精度/断电保持已验证。
- 实板重点：校时后状态栏/锁屏同步，过分钟/午夜推进，重复关机开机保持，熄屏唤醒和音乐播放稳定，RTC掉电OS提示，IRQ11电气上拉与晶体负载参数。CAP_SEL与Offset保留硬件现状，未做晶体校准。
